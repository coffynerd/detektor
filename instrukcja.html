1. Struktura plików w repozytorium GitHub

Przed przystąpieniem do instalacji upewnij się, że w głównym katalogu repozytorium https://github.com/coffynerd/detektor znajdują się następujące pliki:

Nazwa pliku Zawartość / Przeznaczenie
app.py Program główny obsługujący GPIO, filtr ruchu (3x co 4,5 s w oknie 20 s), Web Push API oraz endpointy REST na porcie 5000.

2. Przygotowanie karty microSD (Raspberry Pi Imager)

  1. Pobierz program Raspberry Pi Imager (raspberrypi.com/software) i włóż kartę microSD (16–32 GB) do czytnika.
  2. Wybierz kolejno:
    • Urządzenie (Device): Raspberry Pi Zero (lub Raspberry Pi Zero 2 W)
    • System (OS): Raspberry Pi OS (other) → Raspberry Pi OS Lite (32-bit)
    • Pamięć (Storage): Twoja karta microSD
  3. Kliknij Dalej (Next) → Edytuj ustawienia (Edit Settings) i wypełnij parametry:
    • Nazwa hosta (Hostname): detektor (pozwoli łączyć się przez adres detektor.local)
    • Użytkownik i hasło: np. użytkownik pi oraz wybrane hasło administratora
    • Bezprzewodowa sieć LAN (Wi-Fi): Wpisz nazwę (SSID) i hasło firmowego Wi-Fi, Kraj: PL
    • Zakładka Usługi (Services): Zaznacz Włącz SSH (Enable SSH) → uwierzytelnianie hasłem
  4. Zapisz kartę i po zakończeniu procesu przełóż ją do slotu microSD w Raspberry Pi Zero WH.

3. Tabela połączeń sprzętowych (Pinout GPIO)

⚠️ Zasada bezpieczeństwa: Wszystkie przewody podłączaj przy odłączonym kablu zasilającym USB. Czujnik zasilamy z pinu 3,3 V (Pin 1), co odfiltrowuje szumy z portu USB komputera.
Moduł Wyprowadzenie / Przewód Fizyczny numer nóżki (Pin) Oznaczenie w kodzie (BCM) Sposób połączenia (bez lutowania)
Czujnik PIR DFRobot + (VCC) – czerwony Pin 1 3.3V Power Przewód przejściowy M-F do wtyczki czujnika
Czujnik PIR DFRobot - (GND) – czarny Pin 6 Ground (Masa) Przewód przejściowy M-F do wtyczki czujnika
Czujnik PIR DFRobot D (Sygnał) – zielony Pin 11 GPIO 17 Przewód przejściowy M-F do wtyczki czujnika
Przełącznik ON/OFF Styk 1 (dowolny) Pin 13 GPIO 27 Przewód M-F połączony z przełącznikiem przez WAGO #1
Przełącznik ON/OFF Styk 2 (dowolny) Pin 14 Ground (Masa) Przewód M-F połączony z przełącznikiem przez WAGO #2
Przycisk „Pomoc” (opcja) Styk 1 i Styk 2 Pin 15 oraz Pin 9 GPIO 22 + Masa Rezerwacja w kodzie pod przyszły przycisk chwilowy

5. Uruchomienie instalatora przez SSH (krok po kroku)

  1. Wepnij przewód zasilający micro-USB do gniazda PWR IN w malince, a drugi koniec do tylnego portu USB 3.0 w komputerze przy kasie. Poczekaj ok. 60–90 sekund na pierwsze uruchomienie.
  2. Otwórz terminal (PowerShell lub CMD w Windowsie) i połącz się z malinką: 
    ssh pi@detektor.local
  3. Wklej poniższą komendę, która zainstaluje Gita, pobierze Twoje repozytorium i uruchomi Panel Administratora: 
    sudo apt-get update && sudo apt-get install -y git && git clone https://github.com/coffynerd/detektor.git && cd detektor && sudo python3 admin.py
  4. W menu wybierz opcję 1 (Zainstaluj oprogramowanie i Web Push). Skrypt skonfiguruje usługę systemd (autostart po utracie prądu), wygeneruje klucze VAPID i uruchomi serwer na porcie 5000.
  5. Sprawdź lokalny adres IP malinki komendą hostname -I i wpisz go w Panelu Admina swojej strony WWW (np. http://192.168.1.45:5000 lub http://detektor.local:5000).
